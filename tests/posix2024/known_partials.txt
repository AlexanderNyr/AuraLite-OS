# tests/posix2024/known_partials.txt -- the matrix's "partial" rows, allowlisted.
#
# The drift check (matrix_check.py) requires the set of partial rows in
# docs/posix2024_compliance.md to equal this file EXACTLY, both directions.
# A partial is an honest, documented "interface present but not fully
# functional" row -- it can neither grow silently nor disappear
# undocumented.  One token per line; '#' comments allowed.
#
# Named semaphores (sem_open/sem_close/sem_unlink): POSIX requires them to
#   live on shared memory (/dev/shm); the kernel has no mmap(MAP_SHARED)
#   backing yet, so sem_open fails with ENOSYS.  Process-private unnamed
#   semaphores (sem_init/sem_wait/sem_post/sem_trywait) are implemented and
#   are NOT partials.
# (mq_notify was a partial until Q15, and the System V IPC family until
#   Q14; both are now fully implemented and their rows are ✅ in the matrix.)
sem_open
sem_close
sem_unlink
