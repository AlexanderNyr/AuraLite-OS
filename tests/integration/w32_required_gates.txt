# The Win32 gates that must PASS **non-vacuously** in CI, and the shard that
# owns each one.  Format: "<shard> <case>", one per line.
#
# WHY THIS FILE EXISTS
# --------------------
# Several W32 cases return 0 after printing "SKIP:" when their optional
# mingw-w64 payloads or pinned binaries are absent, so a green runner does
# NOT by itself prove the personality was exercised.  CI therefore asserts
# that each case below both recorded a PASS *and* did not skip.
#
# That list used to be inlined in .github/workflows/integration.yml.  When
# the single `w32` shard was split three ways (2026-09-30) the list had to be
# split with it, and an inlined-and-split list has a failure mode the single
# one did not: a gate dropped from one shard's arm is invisible, because every
# shard still passes its own (now shorter) list.  Keeping the mapping in ONE
# file makes the total checkable -- `make test-unit` runs
# tools/check_w32_gates.py, which pins the count at 16 and cross-checks every
# line against run_all.sh's ALL_CASES and its shard partition.
#
# Cases deliberately NOT listed: the ones that are allowed to skip on a
# checkout without pinned third-party binaries (test_wr2_7zip_launch,
# test_wr2_7zip_live) and the phase subsets that the owning phase gate
# already covers (the w32a11_* family, w32a12..a16, wr1).
